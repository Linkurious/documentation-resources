# LK-SEC-2026-2

## Timeline
- 2025-04-30 [eMudhra](https://en.wikipedia.org/wiki/EMudhra) generated eight intermediate CA certificates (including six for TLS) using a script with insufficient cryptographic entropy, producing extremely weak private keys
- 2026-10-17 A security researcher discovered the flaw, recovered all private keys, and reported the vulnerability to browser vendors
- 2026-10-21 Node.js releases a security release fixing the issue ([source](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases))
- 2026-10-22 Linkurious releases Linkurious Enterprise v4.3.14 fixing the issue
- 2026-10-23 Linkurious notifies all customers about the security fix ([source](https://resources.linkurious.com/linkurious-enterprise-4.3.14-security-improvements-with-node.js))

## Description
Vulnerability in a TLS Root Certificate Authority certificate embedded in Node.js, which is the server framework of Linkurious Enterprise.

## Impact
An attacker able to deploy services on the same network as Linkurious Enterprise can impersonate any Web server Linkurious Enterprise
connects to over TLS, using the weak CA certificates from eMudhra.

## Severity: high
- CVSS v3.1 score: `8.1` (see [severity rules](https://doc.linkurious.com/admin-manual/latest/vulnerabilities/#severity-levels)).
- Patch required.

## Who is affected?
All versions of Linkurious Enterprise up to v4.3.13 (included).

## How can it be patched?
- Upgrade to Linkurious Enterprise v4.3.14
